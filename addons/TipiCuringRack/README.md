# Tipi Curing Rack · v0.1.1 Beta

Bastidor interior opcional para **BurebistaTraditionalTipi**. Los palos usan materiales nativos de The Long Dark; las cuerdas, el tamaño y el sistema de curado se conservan.

**[Descargar](https://github.com/florynstefanache-source/BurebistaTraditionalTipi/raw/refs/heads/main/downloads/TipiCuringRack-v0.1.1.zip)** · [Instalación del tipi y requisitos](../../README.md)

Cierra el juego y copia `Mods/BurebistaTipiCuringRack.dll` en `TheLongDark/Mods`. Conserva los archivos y dependencias del tipi.

## Cómo usarlo

1. Despliega el tipi. El bastidor aparece automáticamente en un lateral del interior.
2. Deja pieles, tripas o retoños frescos en el suelo a menos de **1,8 m** del bastidor.
3. Acércate a menos de **2,5 m** y pulsa **G**.
4. Recoge cada material con la interacción normal del juego.

Tiene **cuatro posiciones para pieles o tripas** y **dos para retoños de abedul o arce**, en un soporte bajo separado. Los palos normales no se curan.

Utiliza el sistema nativo de evolución de objetos, con sus tiempos y progreso. Los materiales colocados cuentan como protegidos para curarse; no se crean copias. No hay coste adicional para que aparezca el bastidor en esta versión.

## Guardado y límites

Los materiales siguen siendo objetos del mundo y conservan el progreso mediante el guardado del juego. No se guarda una lista propia de posiciones: al cargar puede ser necesario pulsar G de nuevo. Al retirar el tipi se liberan como objetos del mundo. No se garantiza curado con la zona descargada.

La versión 0.1.1 modifica únicamente el material de madera y la versión del addon. Compilación comprobada; la validación completa de curado y guardado en partida sigue pendiente.
