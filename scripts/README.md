# Scripts

`build.ps1 -GameDir RUTA` compila los tres proyectos sin instalar nada. Consulta [compilación](../docs/BUILD.md).

`install.ps1 -TLDPath RUTA` copia los tres mods desde `release/Mods` a la instalación indicada, sustituyendo sus archivos. Ejecuta el instalador con el juego cerrado y las dependencias ya instaladas. Para instalar solo determinados componentes utiliza [los ZIP individuales](../downloads/README.md).
